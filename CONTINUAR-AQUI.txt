EJECUCIÓN
Para abrir la aplicación en Windows, usa el archivo Abrir Bolt Pets.cmd de esta
carpeta. Prepara la compilación si hace falta, inicia el servidor local separado
del terminal y abre http://127.0.0.1:4327/. También puede ejecutarse npm run local
para iniciar o npm run open para iniciar y abrir el navegador. El equipo debe
estar encendido; no es una publicación en Internet.

Para abrir directamente el panel, usa Abrir administrador.cmd. Ambos accesos
inician o reutilizan el mismo servidor antes de abrir la página correspondiente.
Abrir solo un enlace en el navegador no inicia el servidor cuando está apagado.
El arranque espera hasta 90 segundos y muestra progreso si el equipo tarda;
conserva el PID del proceso nuevo desde el comienzo en el registro privado.
Si el puerto corresponde a otra aplicación, informa el conflicto sin cerrarla.

Desde esta carpeta, con Node y dependencias instaladas:
  npm run dev
  npm run lint
  npm test
  npm run build

La vista local preparada en esta sesión usa http://127.0.0.1:4327/.
El servidor escucha en 127.0.0.1 por defecto. PORT y HOST permiten configurarlo.
BOLT_DATA_DIR permite indicar una carpeta privada persistente; el valor por defecto
es .bolt-private/operations dentro de la carpeta desde la que se inicia el servidor.
Conservar esa carpeta privada al mover la instalación; no subirla a GitHub ni adjuntarla
en una entrega pública de código. Las claves deben permanecer en variables privadas.
